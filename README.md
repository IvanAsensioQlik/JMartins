Sales Mashup, a Qlik Sense mashup mobile for JMartins

=============================
==================================

Available in https://github.com/IvanAsensioQlik/JMartins

Current version 1.0 28-Sep-2026. Compatible with Qlik Cloud

Author Ivan Felipe Asensio QlikTech Iberia,s.l.


This mashup is useful to create a very dynamic and intuitive user experience using Qlik with your mobile any time any where.
